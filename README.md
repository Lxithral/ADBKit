# ADBKit

一个简洁的 Android ADB 调试快捷工具，支持 Root 快速开关各项调试功能。

## 功能

- **开发者选项** — 一键开关
- **USB 调试** — 一键开关
- **USB 安装** — 一键开关（支持 MIUI）
- **USB 调试安全设置** — 一键开关
- **无线调试** — 一键开关，显示连接地址和端口
- **快捷磁贴** — 5 个 Quick Settings Tile，下拉控制中心即可操作
- **内存管理** — 遵循公平运行内存机制，磁贴操作完自动退出，不常驻后台

## 特性

- 磁贴操作后 10 秒自动退出，不占用后台资源
- 连续点击自动重置计时，不会中断操作
- MIUIX 风格 UI
- 合并 Shell 命令，单次轮询 10 秒

## 要求

- Android 13+ (API 33)
- Root 权限
