# 快捷入口跳转开发者选项并高亮"无线调试"

## 改动 1：快捷入口高亮跳转（AdbScreen.kt:244-246）

把"快捷入口 → 开发者模式"条目的点击 Intent 从裸跳开发者选项改为带高亮参数：

```kotlin
onClick = {
    context.startActivity(
        Intent(android.provider.Settings.ACTION_APPLICATION_DEVELOPMENT_SETTINGS).apply {
            putExtra(android.provider.Settings.EXTRA_FRAGMENT_ARG_KEY, "wireless_debugging")
        }
    )
}
```

- `EXTRA_FRAGMENT_ARG_KEY`（":settings:fragment_args_key"）就是系统设置"搜索 → 点击结果"用的同一套高亮机制：打开开发者选项后自动滚动到无线调试条目并高亮渐隐（即用户要的"闪一下"）。`wireless_debugging` 是 AOSP 开发者选项里无线调试条目的 preference key。
- summary 文案同步改为「跳转开发者选项并定位无线调试」。
- 只改这一处，不动你未提交的 WirelessDebugging.kt / AdbScreen.kt 其他改动。
- verify: 真机点击观察；用 adb 截图辅助确认高亮滚动。

## 改动 2：构建后直接无线安装（本次起固化为惯例）

1. `./gradlew.bat :app:assembleDebug`
2. `adb connect 192.168.0.112:40049`，失败换 `adb connect 172.19.0.1:40049`（USB 已连则直接用 USB 设备）
3. `adb install -r app/build/outputs/apk/debug/app-debug.apk`
- verify: 安装输出 Success；启动 App 复现跳转效果。
- 风险：小米 HyperOS 若忽略该高亮 extra，效果退化为普通打开开发者选项页——我会真机验证并如实报告，届时备选方案是 try `ACTION_WIRELESS_DEBUGGING_SETTINGS`（直接进无线调试子页）兜底。

## 改动 3：持久化"直接安装"偏好（新建项目 AGENTS.md）

在仓库根新建简短 AGENTS.md：每次改动构建 debug 后直接 adb 安装；设备 `192.168.0.112:40049`，备用 `172.19.0.1:40049`；无线端口会变，失效时先查新端口再装。
